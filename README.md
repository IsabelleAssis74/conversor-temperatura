# Conversor de Temperatura

Conversor de temperatura feito com HTML, CSS e JavaScript. O usuário digita um valor e escolhe o tipo de conversão, e o resultado aparece na tela.

🔗 **Veja funcionando:** https://isabelleassis74.github.io/conversor-temperatura

## Tecnologias
- HTML
- CSS
- JavaScript

## Funcionalidades
- Conversão de Celsius para Fahrenheit
- Conversão de Fahrenheit para Celsius
- Conversão de Celsius para Kelvin
- Aviso quando o valor digitado não é um número válido
- Layout que se adapta ao celular

## Como rodar
1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador

## O que aprendi
- Ler valores digitados em um formulário com JavaScript
- Criar funções e usar `if/else` para tratar cada tipo de conversão
- Validar a entrada do usuário e mostrar o resultado na página
